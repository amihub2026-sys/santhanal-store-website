# Santhanal Store Website

Complete single-page cinematic website built with React, Next-compatible components, Vinext and CSS.

## Run locally

1. Install Node.js 22 LTS.
2. Open this project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown in the terminal.

## Production build

Run `npm run build`.

## Main files

- `app/page.tsx` — complete page structure, scroll-controlled video and rotating content.
- `app/globals.css` — complete responsive design, transitions and animations.
- `app/layout.tsx` — page title, description and social sharing metadata.
- `public/temple-journey.mp4` — scroll-controlled temple journey video.
- `public/hero-five-gopurams.png` — five-gopuram hero artwork.
- `public/about-worship.png` — Meenakshi Amman worship scene.
- `public/sandal-abhishekam.png` — sandalwood abhishekam scene.
- `public/shop-reference.png` — temporary shop reference image.

## Before client delivery

Replace the temporary shop reference images and update the address, phone number, WhatsApp number and opening hours in `app/page.tsx`.
